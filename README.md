# Mon CV en ligne

Ce projet est un CV réalisé en HTML et CSS.  
Il a été créé pour apprendre les bases du développement web et l’utilisation de GitHub.

## 📌 Contenu du projet
- Structure HTML du CV  
- Mise en page en CSS  
- Colonne gauche : compétences, langues, qualités  
- Colonne droite : profil, formations, expériences  
- Effets graphiques (hover, zoom, opacité)  
- Version responsive pour mobile  
- Déploiement avec GitHub Pages

## 🎯 Objectif
Apprendre :
- HTML / CSS  
- Organiser un projet web  
- Utiliser GitHub (issues, branches, pull requests)  
- Mettre un site en ligne avec GitHub Pages
